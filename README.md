## About

Entire rework of the gamemode Strike force missions from the campaign to be like mw3 survival but made for bo2 and with more objectives and variety.

## Features

- Custom enemy behavior
- Wave based gamemode 
- New gameplay systems
- Shop to buy troops and perks

## Requirements

- Call of Duty: Black Ops II
- Campaign installed
- Infinity loader with an account
  
## Installation

1. Download the ZIP and extract it.
2. Download infinity loader.
3. Open infinity loader.
4. Sign in.
5. Click on compiler.
6. Create a new project.
7. Rename the project.
8. Select Project game to BO2.
9. Select Project mode to Singleplayer.
10. Click create project.
11. Select the steam icon.
12. Go to main.gsc and delete everything.
13. Go back in the extracted file and go in the .gsc file.
14. Copy paste everything to the main.gsc on the right text you deleted.
15. Launch Bo2 from steam and while in the main menu click on compile project (middle paper icon on infinity loader)
16. A text show up and load the mod then you can start the mission FOB Spectre and play !
